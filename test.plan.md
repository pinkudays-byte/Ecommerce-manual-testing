## Test Plantation 
# Objective 

- Verify that the main e-commerce functionalities work according to the expected behavior and identify defects that could negatively affect the user experience.

# In scope 

- I decided to divide the testing scope into different functional areas. This approach will allow me to apply different testing techniques and identify which types of testing are most appropriate depending on the functionality and characteristics of each area.
- For each area, I will provide an introduction to the testing techniques applied, along with the tools used during the testing process.

## Test Areas 

# 1. Authentication
   - Login
   - Registration
   - Forgot password
   - Validation messages

# 2. Product Management
   - Product display
   - Product details
   - Add to cart
   - Favorites
   - Related products

# 3. Product Discovery
   -  Search
   - Categories
   - Brand
   - Sustainability
   - Price range
   - Sort

# 4. Shopping / Checkout
   - Cart
   - Quantity
   - Address
   - Payment
   - Order completion

# 5. UI / Visual
   - Labels
   - Spelling
   - Images
   - Alignment
   - Margins
